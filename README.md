# Auraluxe — Modern E-Commerce Web Application

Auraluxe is a full-stack e-commerce web application designed for a smooth online shopping experience. Built using core **JavaScript (ES6+)**, **SQL (PostgreSQL/Supabase)**, and **RESTful APIs**, it demonstrates responsive UI components, dynamic shopping cart management, and efficient database modeling.
Tech Stack & Tools
Frontend: HTML5, CSS3 (Flexbox/CSS Grid), JavaScript (ES6+ / Fetch API)

Backend & Database: MongoDB(NOSQL)

API Testing & Tools: RESTful APIs, Git & GitHub, VS Code

Key Features
Dynamic Product Catalog: Fetches and renders product items dynamically using REST API endpoints.

Interactive Shopping Cart: Real-time state management for adding, updating, and removing items with price calculations.

Responsive UI/UX: Mobile-first, fully adaptable design supporting multiple desktop and mobile viewports.

Structured SQL Database: Custom PostgreSQL schemas managing users, product inventories, and transaction logs.

Edge-Case Validation: Form validation and robust API error handling for seamless user experience.
